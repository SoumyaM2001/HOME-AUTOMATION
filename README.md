# Home Automation System

## Project Description
A web-based Home Automation System developed using Python Flask. This project allows users to monitor and control electrical appliances through a web interface.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite Database
-  ESP8266 (if used in the project)

## Features
- Web-based appliance control
- ON/OFF control of connected devices
- User-friendly interface
- Database integration
- Hardware communication

## Project Structure
```text
HOME_AUTOMATION/
├── main.py
├── requirements.txt
├── templates/
└── home.db
```

## Installation
1. Clone this repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python main.py`
4. Open the local URL displayed in the terminal.

## Deployment
The application can be deployed using Render.
